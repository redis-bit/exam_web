# 🔐 Исправление ролей пользователей

## Проблема:
Мы дали обычному пользователю роль `admin` только для тестирования новостей. Это неправильно с точки зрения безопасности.

## Варианты решения:

### 🎯 **Вариант 1: Изменить роль на section_chief**
```sql
UPDATE users 
SET role = 'section_chief'
WHERE id = 'ea93334d-bd5e-4e88-a0cc-aa6240005867';
```
**Результат:** 
- Пользователь станет начальником участка
- Не сможет создавать новости (согласно ТЗ)
- Сможет управлять работниками своего участка

### 🎯 **Вариант 2: Создать отдельного администратора**
1. Зарегистрировать нового пользователя с email админа
2. Добавить его в таблицу `users` с ролью `admin`
3. Текущего пользователя сделать `section_chief`

### 🎯 **Вариант 3: Расширить права на создание новостей**
Изменить логику в коде, чтобы начальники участков тоже могли создавать новости:
```typescript
const isAdmin = user?.role === 'admin' || user?.role === 'admin_assistant' || user?.role === 'section_chief'
```

## Рекомендация:
**Вариант 1** - самый простой и правильный для демонстрации системы.
