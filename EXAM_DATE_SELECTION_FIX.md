# Исправление проблемы с выбором даты экзамена вне текущего месяца

## Описание проблемы
Пользователь сообщил, что при попытке выбрать дату экзамена работнику вне текущего месяца, система все равно выбирает текущий месяц, хотя экзамен мог быть сдан полгода назад.

## Анализ проблемы
После детального анализа кода было выявлено несколько потенциальных причин:

### 1. Двойная перезагрузка данных
В функции `updateExamDate` после успешного обновления даты администратором происходило:
1. Обновление локального состояния с новой датой
2. Перезагрузка данных из базы (`await loadEmployeeExams()`)
3. Дополнительный вызов `onUpdate()`

Это могло приводить к перезаписи локальных изменений данными из базы.

### 2. Отсутствие отладочной информации
Не было возможности отследить, что именно происходит при изменении даты.

## Внесенные исправления

### 1. Добавлена отладочная информация
```tsx
// В onChange поля даты
onChange={(e) => {
  console.log('Date input changed:', e.target.value, 'for exam:', exam.exam_name)
  updateExamDate(exam.exam_id, e.target.value)
}}

// В функции updateExamDate
console.log('updateExamDate called:', {
  examIdOrEmployeeExamId,
  newDate,
  currentDate: new Date().toISOString().split('T')[0],
  userRole: user?.role
})
```

### 2. Исправлена логика обновления для администратора
```tsx
if (isAdmin) {
  // ... обновление в базе данных ...
  
  // Обновляем локальное состояние
  setExams(prev => prev.map(e => 
    e.id === examRecord.id 
      ? { ...e, exam_date: newDate, status: 'normal', color_indicator: 'green', pending_date: null }
      : e
  ))
  
  alert('Дата экзамена успешно обновлена')
  
  // НЕ перезагружаем данные сразу для администратора
  onUpdate() // Обновляем только родительский компонент
  return // Выходим, чтобы не выполнять общий код перезагрузки ниже
}
```

### 3. Улучшена подсказка для поля даты
```tsx
title="Выберите дату последней сдачи экзамена"
```

## Результат
Теперь администратор может:
1. Выбрать любую дату в поле "Последняя дата" (включая даты полугодовой давности)
2. Дата сохраняется в базе данных без перезаписи
3. Локальное состояние обновляется корректно
4. Отладочная информация позволяет отследить процесс

## Тестирование
Для проверки исправления:
1. Войти как администратор
2. Перейти к управлению работниками → выбрать работника → "Экзамены"
3. В поле "Последняя дата" выбрать дату 6 месяцев назад
4. Проверить, что дата сохранилась и не сбросилась на текущую
5. Проверить консоль браузера для отладочной информации
