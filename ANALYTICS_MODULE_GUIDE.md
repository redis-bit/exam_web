# Модуль "Статистика и дашборд"

## Обзор
Модуль аналитики предоставляет комплексную систему мониторинга экзаменов работников с визуализацией статистики и уведомлениями.

## Компоненты

### 1. AnalyticsDashboard
**Расположение:** `src/components/Analytics/AnalyticsDashboard.tsx`

Главный компонент модуля аналитики с тремя режимами просмотра:
- **Обзор** - общая панель с быстрым доступом к статистике и уведомлениям
- **Статистика** - детальная аналитика по участкам
- **Уведомления** - центр уведомлений о просроченных и предстоящих экзаменах

### 2. StatisticsOverview
**Расположение:** `src/components/Statistics/StatisticsOverview.tsx`

Компонент статистики включает:
- Общую статистику по системе (участки, работники, экзамены)
- Детальную статистику по каждому участку
- Цветовую индикацию состояния:
  - 🔴 Красный - просроченные экзамены (критично)
  - 🟡 Желтый - предстоящие экзамены (внимание)
  - 🔵 Синий - ожидающие подтверждения (информация)
  - 🟢 Зеленый - нормальное состояние

### 3. NotificationCenter
**Расположение:** `src/components/Notifications/NotificationCenter.tsx`

Центр уведомлений с функциями:
- Фильтрация по типам уведомлений
- Отображение просроченных экзаменов с указанием дней просрочки
- Предстоящие экзамены с обратным отсчетом
- Уведомления о изменениях, ожидающих подтверждения

## Хук useStatistics
**Расположение:** `src/hooks/useStatistics.ts`

Централизованное управление данными статистики:
- Загрузка статистики по участкам
- Получение уведомлений из базы данных
- Обработка ролевого доступа (начальники участков видят только свой участок)
- Автоматическое обновление данных

## Интеграция с базой данных

### Используемые функции PostgreSQL:
- `get_section_statistics(section_uuid)` - получение статистики по участку
- Представление `exam_status_view` - статусы экзаменов с цветовой индикацией

### Цветовая схема (согласно ТЗ 4.6):
- **Красный (red)** - просроченные экзамены
- **Желтый (yellow)** - экзамены в ближайшие 30 дней
- **Синий (blue)** - ожидающие подтверждения изменения
- **Зеленый (green)** - нормальное состояние

## Доступ по ролям

### Администратор и помощник администратора:
- Полный доступ ко всей статистике
- Просмотр данных по всем участкам
- Все типы уведомлений

### Начальник участка:
- Статистика только по своему участку
- Уведомления только по работникам своего участка
- Возможность просмотра изменений, требующих подтверждения

## Навигация
Модуль доступен через кнопку "📊 Аналитика" в главном меню Dashboard.
