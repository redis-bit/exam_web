# Исправление проблемы с кнопками в таблице работников

## 🚨 Проблема:
Кнопки действий (Экзамены, Редактировать, Удалить) заходили за границы формы, были видны не все кнопки.

## ✅ Что исправлено:

### **1. Увеличена ширина колонки действий:**
- **Минимальная ширина:** с 200px до 280px
- **Максимальная ширина:** 320px (для ограничения)
- **Отступ справа:** 15px для дополнительного пространства

### **2. Оптимизированы кнопки:**
- **Размер:** более компактные (4px 8px вместо 6px 12px)
- **Шрифт:** уменьшен до 11px
- **Минимальная ширина:** 70px для единообразия
- **Отступы:** 5px между кнопками, 3px снизу

### **3. Разрешен перенос:**
- **white-space:** изменен с `nowrap` на `normal`
- **Кнопки могут переноситься** на следующую строку при необходимости
- **Межстрочный интервал:** уменьшен до 1.2

### **4. Улучшена адаптивность:**
- **Минимальная ширина таблицы:** увеличена до 800px
- **На мобильных:** кнопки располагаются в столбик
- **Дополнительное место:** 300px для мобильных устройств

## 🎯 Результат:

### **На десктопе:**
- ✅ Все кнопки видны полностью
- ✅ Кнопки компактные и аккуратные
- ✅ При необходимости переносятся на новую строку
- ✅ Достаточно места для всех действий

### **На мобильных:**
- ✅ Кнопки располагаются вертикально
- ✅ Каждая кнопка на полную ширину
- ✅ Удобно нажимать на сенсорных экранах
- ✅ Горизонтальная прокрутка для таблицы

```css
.actions-cell {

  min-width: 280px;          /* Больше места */
  max-width: 320px;          /* Ограничиваем */
  text-align: left;          /* Выравнивание */
  padding-right: 15px;       /* Отступ */
  line-height: 1.2;          /* Межстрочный интервал */
}

.actions-cell .btn {
  margin-right: 5px;         /* Отступ между кнопками */

  font-size: 11px;           /* Меньший шрифт */
  min-width: 70px;           /* Минимальная ширина */
}
```

### **Адаптивность:**
