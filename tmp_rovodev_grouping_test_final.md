# Финальный тест группировки экзаменов

## Что реализовано:

1. **Группировка по первым двум буквам**: 
   - ОТ_б, ОТ_пмп, ОТ_рпо, ОТ_сиз → группа "ОТ"
   - ПБ_основы, ПБ_газ → группа "ПБ"
   - Одиночные экзамены остаются отдельно

2. **Принцип колоды карт**:
   - В свернутом виде показывается только ближайший по дате экзамен
   - Остальные экзамены "лежат под ним"

3. **Фиолетовые заголовки групп**:
   - Показывают префикс группы (например "ОТ", "ПБ", "ЭБ")
   - Фиолетовый градиент #8b5cf6 → #a855f7 для легкого распознавания
   - Стрелка ▼ для свернутой группы, ▲ для развернутой
   - Tooltip показывает все экзамены группы при наведении

4. **Интерактивность**:
   - Клик по заголовку группы раскрывает/сворачивает
   - Клик по ячейке группы также раскрывает группу
   - **Автоматическое сворачивание**: развернутые группы автоматически сворачиваются через 10 секунд

5. **Счетчик экзаменов**:
   - Фиолетовый кружок с числом в правом верхнем углу ячейки
   - Показывает количество экзаменов в группе у данного сотрудника

6. **Компактный режим отображения**:
   - По умолчанию скрыты дополнительные колонки (Участок, Профессия, Дата создания)
   - Чекбокс "Показать дополнительные данные" для их отображения при необходимости
   - Фокус на главном - ФИО и экзамены

7. **Масштабирование таблицы**:
   - Чекбокс "Компактный масштаб (50%)" для уменьшения таблицы в 2 раза
   - Позволяет увидеть больше данных одновременно для общего обзора
   - Полезно при большом количестве сотрудников

8. **Сохранение стилей таблицы**:
   - Базовые стили ExcelTable не изменены
   - Заголовки и ячейки остаются выровненными

## Логика работы:

- **Свернутая группа**: Показывает дату ближайшего экзамена + счетчик
- **Развернутая группа**: Показывает все экзамены группы в отдельных колонках
- **Сортировка в группе**: По дате следующего экзамена (ближайший первый)

## Тестирование:

1. Откройте Аналитика → Таблицы
2. Обратите внимание: по умолчанию показаны только ФИО и экзамены (компактный режим)
3. Найдите чекбоксы в правом верхнем углу:
   - "Показать дополнительные данные" 
   - "Компактный масштаб (50%)"
4. Активируйте первый чекбокс - появятся колонки Участок, Профессия, Дата создания
5. Деактивируйте первый чекбокс - дополнительные колонки скроются
6. Активируйте второй чекбокс - таблица уменьшится в 2 раза для общего обзора
7. Деактивируйте второй чекбокс - таблица вернется к нормальному размеру
8. Найдите группы экзаменов с фиолетовыми заголовками
9. Обратите внимание: заголовок показывает префикс группы (например "ОТ") 
10. Наведите курсор на заголовок - tooltip покажет все экзамены группы
11. Кликните по заголовку группы - должна развернуться, показав все экзамены отдельно
12. Подождите 10 секунд - группа должна автоматически свернуться обратно
13. Попробуйте кликнуть еще раз по заголовку для ручного сворачивания
14. Проверьте счетчики экзаменов в ячейках сотрудников

## Автоматическое сворачивание:

- При раскрытии группы запускается таймер на 10 секунд
- Если группу свернуть вручную, таймер отменяется
- Если раскрыть группу повторно, старый таймер сбрасывается и запускается новый
- При закрытии страницы все таймеры автоматически очищаются

## Логика отображения в ячейках:

В каждой ячейке сотрудника показывается дата его личного ближайшего экзамена из группы. У разных сотрудников может отображаться дата разных экзаменов из одной группы - у кого ОТ_рпо, у кого ОТ_сиз, в зависимости от того, какой экзамен у конкретного сотрудника подходит раньше.
