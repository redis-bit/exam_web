# Настройка Supabase Auth для тестирования

## Проблема: "Email not confirmed"

Когда вы создаете пользователя через систему и пытаетесь войти, может возникнуть ошибка "Email not confirmed". Вот несколько способов решения:

## Решение 1: Отключить подтверждение email (Рекомендуется для тестирования)

1. Откройте Supabase Dashboard
2. Перейдите в **Authentication** → **Settings**
3. Найдите секцию **"User Signups"**
4. **Отключите** опцию **"Enable email confirmations"**
5. Сохраните изменения

## Решение 2: Использовать нашу SQL функцию

1. В Supabase Dashboard перейдите в **SQL Editor**
2. Выполните скрипт `database/create_confirmed_user.sql`
3. Система автоматически будет использовать эту функцию при создании пользователей

## Решение 3: Ручное подтверждение email в Dashboard

1. Перейдите в **Authentication** → **Users**
2. Найдите созданного пользователя
3. Нажмите на пользователя для редактирования
4. Установите дату в поле **"Email Confirmed At"**
5. Сохраните изменения

## Пошаговое тестирование после настройки

### Шаг 1: Создание участка
1. Войдите как администратор
2. Перейдите в "🏢 Участки"
3. Создайте участок "Тестовый участок"

### Шаг 2: Создание пользователя
1. Перейдите в "👤 Пользователи"
2. Создайте пользователя:
   - ФИО: "Тестовый Пользователь"
   - Email: "test@example.com"
   - Пароль: "test123"
   - Роль: "Начальник участка"
   - Участок: "Тестовый участок"

### Шаг 3: Проверка входа
1. Выйдите из системы
2. Войдите с данными:
   - Email: test@example.com
   - Пароль: test123

## Ожидаемый результат

✅ Пользователь должен успешно войти в систему  
✅ Должен видеть только свой участок  
✅ Должен иметь доступ к управлению работниками  
✅ Должен видеть аналитику только по своему участку  

## Если проблемы продолжаются

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что все SQL скрипты выполнены
3. Проверьте RLS политики в базе данных
4. Убедитесь, что пользователь создался в таблице `auth.users`

## Дополнительная диагностика

Выполните в SQL Editor:
```sql
-- Проверить пользователей в auth.users
SELECT id, email, email_confirmed_at, created_at 
FROM auth.users 
WHERE email = 'test@example.com';

-- Проверить пользователей в нашей таблице
SELECT id, full_name, email, role, section_id, is_active 
FROM users 
WHERE email = 'test@example.com';
```

Оба запроса должны вернуть данные пользователя.
