# 🔍 Отладка роли администратора

## Проблема:
Не отображается кнопка "Создать новость" у администратора.

## Шаги для диагностики:

### 1. Откройте консоль браузера (F12)
- Перейдите во вкладку Console
- Перейдите в раздел "📰 Новости"
- Посмотрите на логи в консоли

### 2. Ожидаемые логи:
```
Текущий пользователь: {id: "...", role: "admin", ...}
Роль пользователя: admin
Может создавать новости: true
```

### 3. Возможные проблемы:

#### A. Пользователь не загружен:
```
Текущий пользователь: null
Роль пользователя: undefined
Может создавать новости: false
```
**Решение:** Проблема с аутентификацией, проверьте useAuth

#### B. Роль не "admin":
```
Текущий пользователь: {id: "...", role: "section_chief", ...}
Роль пользователя: section_chief
Может создавать новости: false
```
**Решение:** Пользователь не является администратором

#### C. Роль не установлена:
```
Текущий пользователь: {id: "...", role: null, ...}
Роль пользователя: null
Может создавать новости: false
```
**Решение:** Нужно установить роль в таблице users
