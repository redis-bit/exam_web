# Тестирование изменения дат экзаменов

## Проблема
Пользователь ввел даты экзаменов, они отправились на согласование, но у администратора 0 запросов на подтверждение.

## Что нужно проверить:

### 1. Выполните SQL запрос для отладки
Выполните в Supabase SQL Editor код из файла `tmp_rovodev_debug_admin_notifications.sql`

Это покажет:
- Есть ли запросы на подтверждение в таблице `approval_requests`
- Есть ли уведомления для администраторов в таблице `user_notifications`
- Кто является администратором в системе
- Какие экзамены были недавно обновлены

### 2. Возможные причины проблемы:

#### A. Нет администраторов с правильной ролью
- В таблице `users` нет пользователей с ролью `admin` или `admin_assistant`
- Администраторы помечены как неактивные (`is_active = false`)

#### B. Функция `request_exam_date_change` не создает уведомления
- Ошибка в функции создания уведомлений
- Нет прав на запись в таблицу `user_notifications`

#### C. Проблема с интерфейсом
- Панель подтверждений не загружает данные
- Фильтрация запросов работает неправильно

### 3. Быстрая проверка в консоли браузера
Откройте консоль браузера (F12) и посмотрите:
- Есть ли ошибки при загрузке панели подтверждений
- Вызывается ли функция `request_exam_date_change`
- Какие параметры передаются в функцию
