# Инструкция по синхронизации пользователей

## Проблема решена! 🎉

Ошибка 403 возникала из-за попытки использовать Admin API без соответствующих прав. Теперь синхронизация работает через SQL функцию.

## Как использовать синхронизацию

### Шаг 1: Выполните SQL скрипты
В Supabase Dashboard → SQL Editor выполните по порядку:
```sql
-- 1. Основная функция синхронизации
database/sync_auth_users.sql

-- 2. Автоматический триггер (если еще не выполнен)
database/auto_create_user_profile.sql
```

### Шаг 2: Используйте кнопку синхронизации
1. Войдите как администратор
2. Перейдите в "👤 Пользователи"
3. Нажмите "🔄 Синхронизировать"
4. Дождитесь сообщения о результате

## Что происходит при синхронизации

✅ **Находит всех пользователей** из `auth.users` с подтвержденным email  
✅ **Проверяет отсутствие** в таблице `users`  
✅ **Добавляет недостающих** с ролью "Начальник участка" по умолчанию  
✅ **Показывает результат** с количеством и списком email'ов  

## Ожидаемый результат

После синхронизации вы увидите сообщение:
```
Синхронизация завершена!

Добавлено пользователей: 1

Пользователи:
- test@example.com
```

## Если синхронизация не нужна

Сообщение будет:
```
Синхронизация завершена!

Все пользователи уже синхронизированы.
```

## Дальнейшая работа

После синхронизации:
1. **Обновите список** пользователей
2. **Отредактируйте пользователя** при необходимости (измените роль, привяжите к участку)
3. **Протестируйте вход** под синхронизированным пользователем
4. **Проверьте аналитику** и ролевой доступ

## Автоматическая синхронизация

После выполнения `auto_create_user_profile.sql` все новые пользователи будут автоматически добавляться в таблицу `users` при регистрации. Ручная синхронизация понадобится только для существующих пользователей.
