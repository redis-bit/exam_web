# Исправление создания работников с автоматическими экзаменами

## Проблема
После подтверждения администратором создания работника экзамены из шаблона профессии не создавались автоматически.

## Решение

### 1. Создана новая SQL функция `create_employee_with_approval`
- **Для администраторов**: создает работника сразу с экзаменами из шаблона
- **Для обычных пользователей**: отправляет запрос на подтверждение

### 2. Исправлена функция `process_approval_request`
- При подтверждении создания работника автоматически создаются экзамены из шаблона профессии
- Все экзамены создаются с пустыми датами (`'1900-01-01'`) для последующего заполнения

### 3. Обновлена логика в React приложении
- Используется новая RPC функция `create_employee_with_approval`
- Разная обработка результата для администраторов и обычных пользователей

## Логика работы

### Для администраторов:
1. Создают работника через форму
2. Функция `create_employee_with_approval` создает работника сразу
3. Автоматически создаются экзамены из шаблона профессии с пустыми датами
4. Работник появляется в списке
5. При нажатии "Экзамены" показываются поля для ввода дат

### Для обычных пользователей:
1. Создают работника через форму
2. Функция `create_employee_with_approval` создает запрос на подтверждение
3. Администратор видит запрос в панели подтверждений
4. При подтверждении:
   - Создается работник
   - Автоматически создаются экзамены из шаблона с пустыми датами
   - Работник появляется в списке
   - При нажатии "Экзамены" показываются поля для ввода дат

## Структура экзаменов после создания

Все экзамены создаются с:
- `exam_date: '1900-01-01'` (пустая дата)
- `next_exam_date: '1900-01-01'` (пустая дата)
- `pending_date: NULL`
- `pending_until: NULL`

Это позволяет пользователям и администраторам заполнять даты по мере необходимости.
