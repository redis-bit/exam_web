🐳 КОМАНДЫ ДЛЯ DOCKER РАЗВЕРТЫВАНИЯ:

=== ОСНОВНЫЕ КОМАНДЫ ===

1. Сборка образа:
docker build -t exam-management-app .

2. Запуск контейнера:
docker run -d -p 8080:8080 --name exam-app exam-management-app

3. Проверка статуса:
docker ps

=== ПРОВЕРКА РАБОТЫ ===

Откройте в браузере: http://localhost:8080

=== УПРАВЛЕНИЕ ===

Просмотр логов:
docker logs exam-app

Остановка:
docker stop exam-app

Перезапуск:
docker restart exam-app

Удаление:
docker stop exam-app && docker rm exam-app

=== ПЕРЕСБОРКА ПОСЛЕ ИЗМЕНЕНИЙ ===

docker stop exam-app
docker rm exam-app
docker build -t exam-management-app .
docker run -d -p 8080:8080 --name exam-app exam-management-app

=== ДЛЯ ДОСТУПА ИЗ ИНТЕРНЕТА ===

Установите ngrok:
ngrok http 8080

Или разверните на VPS сервере с тем же командами.
