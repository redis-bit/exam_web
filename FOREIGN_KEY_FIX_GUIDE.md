# Исправление проблемы с внешним ключом

## 🚨 Проблема:
Ошибка `violates foreign key constraint "users_id_fkey"` означает, что таблица `users` имеет внешний ключ на колонку `id`, который ссылается на `auth.users.id`. При создании пользователя только в локальной таблице этот ключ нарушается.
