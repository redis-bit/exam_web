## 🏗️ Архитектура системы

### База данных (PostgreSQL в Supabase)
- **11 таблиц** с полными связями
- **Row Level Security** для 3 ролей пользователей
- **Автоматические триггеры** для расчета дат экзаменов
- **Функции** для статистики и валидации
- **Представления** для удобного отображения данных

### Frontend (React + TypeScript)
- **Аутентификация** через Supabase Auth
- **Типизированный клиент** для работы с API
- **Адаптивный дизайн** с приоритетом на мобильные устройства
- **Автоматическое тестирование** подключения к БД

### Роли и права доступа
1. **Администратор** - полный доступ ко всем функциям
2. **Помощник администратора** - просмотр всех данных, подтверждение изменений
3. **Начальник участка** - доступ только к своему участку

## 🔧 Техническая информация

### Требования
- Node.js 16+
- npm или yarn
- Современный браузер
- Аккаунт Supabase (бесплатный)

### Зависимости
- React 18.2.0
- TypeScript 4.9.5
- @supabase/supabase-js 2.38.4
- react-router-dom 6.20.1

### Масштабируемость
- **Текущая нагрузка**: 200 работников, 3 участка, 15 пользователей
- **Планируемая**: 5000 работников, 50 участков, без ограничений пользователей
- **База данных**: PostgreSQL с индексами для оптимизации
