# ИСПРАВЛЕНИЕ: Проблема с навигацией календаря при выборе даты экзамена

## Описание проблемы
Пользователь нажимает на стрелочки навигации календаря (следующий/предыдущий месяц) для поиска нужной даты, но это срабатывает как изменение даты и отправляет запрос администратору: "Запрос на изменение даты отправлен администратору на рассмотрение".

## Причина проблемы
HTML `input type="date"` срабатывает `onChange` при любом взаимодействии с календарем, включая:
- Навигацию по месяцам (стрелки ← →)
- Навигацию по годам
- Клики по заголовку календаря

## Решение
Полностью переработана логика обработки изменений даты:

### 1. Убран onChange для обновления даты
```tsx
onChange={(e) => {
  // НЕ обновляем дату в onChange - только логирование
  // Это предотвращает срабатывание при навигации по календарю
}}
```

### 2. Добавлен onBlur для сохранения
```tsx
onBlur={(e) => {
  const newDate = e.target.value
  const currentDate = exam.exam_date
  
  // Обновляем дату только при потере фокуса и если дата действительно изменилась
  if (newDate && newDate !== currentDate) {
    updateExamDate(exam.exam_id, newDate)
  }
}}
```

### 3. Добавлен onKeyDown для Enter
```tsx
onKeyDown={(e) => {
  if (e.key === 'Enter') {
    // Сохранение по нажатию Enter
    if (newDate && newDate !== currentDate) {
      updateExamDate(exam.exam_id, newDate)
      target.blur()
    }
  }
}}
```

### 4. Добавлено отслеживание фокуса
```tsx
const [dateInputFocused, setDateInputFocused] = useState<string | null>(null)
```

### 5. Улучшена подсказка пользователю
```
"Выберите дату и нажмите Enter или кликните вне поля для сохранения. НЕ нажимайте на стрелки навигации календаря!"
```

## Результат
Теперь пользователь может:
1. ✅ Свободно навигировать по календарю стрелками
2. ✅ Выбрать нужную дату кликом
3. ✅ Сохранить дату нажатием Enter или кликом вне поля
4. ❌ Случайные запросы при навигации больше НЕ отправляются

## Способы сохранения даты
1. **Enter** - нажать Enter после выбора даты
2. **Клик вне поля** - кликнуть в любое место вне календаря
3. **Tab** - перейти к следующему полю

## Отладочная информация
Добавлены подробные логи для отслеживания:
- Фокус на поле
- Изменения в календаре
- Потеря фокуса
- Нажатие Enter
- Реальные обновления даты

4. Использовать стрелки навигации календаря для поиска нужного месяца

6. Выбрать дату и нажать Enter или кликнуть вне поля
7. Убедиться, что запрос отправляется только при реальном выборе даты
