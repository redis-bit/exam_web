# Руководство по тестированию системы

## Пошаговое тестирование системы

### 1. Подготовка базы данных
Убедитесь, что выполнены все SQL скрипты:
```sql
-- В Supabase SQL Editor выполните по порядку:
database/01_create_tables.sql
database/02_functions_and_triggers.sql  
database/03_rls_policies.sql
database/04_test_data.sql
database/create_confirmed_user.sql  -- Новая функция для создания пользователей
```

### 2. Создание участка
1. Войдите как администратор
2. Перейдите в "🏢 Участки"
3. Нажмите "Добавить участок"
4. Введите название (например, "Участок №1")
5. Сохраните

### 3. Создание пользователя участка
1. Перейдите в "👤 Пользователи"
2. Нажмите "Добавить пользователя"
3. Заполните данные:
   - ФИО: "Иванов Иван Иванович"
   - Email: "ivanov@company.com"
   - Пароль: "password123"
   - Роль: "Начальник участка"
   - Участок: выберите созданный участок
4. Сохраните

**Важно:** После создания пользователя система покажет сообщение с информацией о том, как пользователь может войти в систему.

### 4. Создание профессии и экзаменов
1. Перейдите в "👔 Профессии"
2. Создайте профессию для участка
3. Добавьте экзамены к профессии

### 5. Создание работника
1. Перейдите в "👥 Работники"
2. Создайте работника, привязав его к профессии
3. Система автоматически создаст экзамены для работника

### 6. Тестирование входа под пользователем участка
1. Выйдите из системы
2. Войдите используя данные созданного пользователя:
   - Email: ivanov@company.com
   - Пароль: password123

### 7. Проверка функционала начальника участка
После входа под пользователем участка проверьте:
- Доступ только к своему участку
- Возможность управления работниками участка
- Просмотр статистики только по своему участку
- Уведомления только по работникам участка

### 8. Тестирование модуля аналитики
1. Перейдите в "📊 Аналитика"
2. Проверьте:
   - Общую статистику
   - Статистику по участкам
   - Центр уведомлений
   - Фильтрацию уведомлений

## Возможные проблемы и решения

### Проблема: "Email not confirmed"
**Решение:** 
1. Выполните SQL скрипт `database/create_confirmed_user.sql`
2. Или в Supabase Dashboard → Authentication → Settings отключите "Enable email confirmations"

### Проблема: Пользователь создается, но не может войти
**Решение:**
1. Проверьте, что функция `create_confirmed_user` выполнена
2. Убедитесь, что в таблице `auth.users` есть запись с `email_confirmed_at`
3. Проверьте RLS политики

### Проблема: Начальник участка видит всех работников
**Решение:**
1. Проверьте RLS политики в `database/03_rls_policies.sql`
2. Убедитесь, что у пользователя правильно указан `section_id`

3. Тестирование фильтров
4. Проверка обновления данных
