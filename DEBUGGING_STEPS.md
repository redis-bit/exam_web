# Пошаговая диагностика проблем

## Проблемы для решения:

1. ❌ **Синхронизация не работает** - пользователь есть в auth.users, но нет в public.users
2. ❌ **Создание пользователя не работает** - ошибка "Database error saving new user"
3. ✅ **Добавлена функция удаления** пользователей

## Шаг 1: Диагностика базы данных

Выполните в Supabase Dashboard → SQL Editor:
```sql
-- Скопируйте и выполните содержимое файла:
database/debug_users.sql
```

Это покажет:
- Всех пользователей в auth.users
- Всех пользователей в public.users  
- Пользователей, которые есть в auth, но нет в public
- Результат работы функции синхронизации
- Состояние триггеров

## Шаг 2: Исправление функций

Выполните SQL скрипты по порядку:
```sql
-- 1. Функции удаления (для очистки тестовых данных)
database/delete_user_functions.sql

-- 2. Исправленная синхронизация
database/sync_auth_users.sql

-- 3. Автоматический триггер
database/auto_create_user_profile.sql
```

## Шаг 3: Тестирование синхронизации

1. **Нажмите "🔄 Синхронизировать"** в интерфейсе
2. **Проверьте результат** - должно показать количество синхронизированных пользователей
3. **Обновите список** пользователей

## Шаг 4: Тестирование создания пользователя

1. **Попробуйте создать нового пользователя** через интерфейс
2. **Если ошибка** - проверьте консоль браузера на детали
3. **Проверьте RLS политики** - возможно блокируют создание

## Шаг 5: Очистка тестовых данных

Если накопилось много тестовых пользователей:
```sql
-- Удалит всех пользователей с email содержащими test, example, demo
SELECT cleanup_test_users();
```

## Возможные причины проблем:

### Синхронизация не работает:
- ❌ Функция `sync_auth_users_to_users_table` не создана
- ❌ Нет прав на выполнение функции
- ❌ Пользователь не подтвердил email (`email_confirmed_at` = NULL)

### Создание пользователя не работает:
- ❌ RLS политики блокируют INSERT в таблицу users
- ❌ Нарушение ограничений (unique email, foreign key на section_id)
- ❌ Функция `create_confirmed_user` не работает

### Триггер не срабатывает:
- ❌ Триггер `on_auth_user_created` не создан
- ❌ Функция `handle_new_user` имеет ошибки

✅ Удаление пользователей работает (для очистки тестовых данных)
