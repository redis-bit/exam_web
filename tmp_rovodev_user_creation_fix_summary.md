# Исправление ошибки создания пользователей

## Проблема
При создании работника возникала ошибка:
```
POST https://dvdribnzlrbmqzeurino.supabase.co/rest/v1/rpc/create_confirmed_user 404 (Not Found)
```

Функция `create_confirmed_user` не найдена в базе данных.

## Решение

### 1. Упрощена функция создания пользователей
- Заменили вызов несуществующей функции `create_confirmed_user` на `create_local_user`
- Убрали сложную fallback логику
- Упростили процесс создания пользователей

### 2. Обновлен код в useUsers.ts
- Удален параметр `user_password` (не нужен для локальных пользователей)
- Упрощена логика обработки ошибок
- Добавлено автоматическое обновление списка пользователей после создания

### 3. Создан SQL скрипт для функции create_local_user
- Файл: `tmp_rovodev_create_local_user_fix.sql`
- Функция создает пользователя только в таблице `public.users`
- Проверяет уникальность email
- Возвращает UUID созданного пользователя

## Изменения в файлах

### src/hooks/useUsers.ts
- Заменен вызов `create_confirmed_user` на `create_local_user`
- Удален параметр `user_password`
- Упрощена логика обработки результата
- Удален весь fallback код
- Добавлено обновление списка пользователей

### tmp_rovodev_create_local_user_fix.sql (новый файл)
- SQL скрипт для создания функции `create_local_user`
- Включает проверку уникальности email
- Правильная обработка типов данных
- Установка прав доступа
