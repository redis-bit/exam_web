# Руководство по Excel-таблице в аналитике

## 🎯 Описание
Новая Excel-подобная таблица заменила сложную интерактивную таблицу в разделе "Аналитика" → "Таблицы". Теперь данные о работниках и их экзаменах отображаются в простом и понятном формате.

## 📊 Структура таблицы

### Фиксированные колонки:
1. **ФИО работника** - полное имя сотрудника
2. **Участок** - название участка работы
3. **Профессия** - профессиональный шаблон
4. **Дата создания** - когда был создан работник

### Динамические колонки экзаменов:
- Каждый экзамен отображается в отдельной колонке
- В ячейке показана дата сдачи экзамена
- Цветовая индикация статуса прямо в ячейке
- Если экзамен не назначен, отображается "-"

## 🎨 Цветовая индикация статусов

- 🔴 **Красный (Просрочен)** - экзамен просрочен
- 🟡 **Желтый (Скоро)** - экзамен истекает в течение 30 дней
- 🟢 **Зеленый (Норма)** - экзамен в норме
- 🔵 **Синий (Ожидает)** - ожидает подтверждения изменений

## ⚡ Функциональность

### Сортировка
- Кликните по любому заголовку колонки для сортировки
- Повторный клик меняет направление сортировки (↑/↓)
- Активная колонка сортировки выделена стрелкой

### Поиск
- Введите текст в поле поиска для фильтрации данных
- Поиск работает по всем колонкам одновременно
- Поиск не чувствителен к регистру

### Обновление данных
- Кнопка "Обновить" загружает актуальные данные из базы
- Автоматическое обновление при изменении секции (для начальников участков)

## 👥 Права доступа

- **Администраторы** - видят всех работников всех участков
- **Начальники участков** - видят только работников своего участка
- **Помощники администратора** - видят всех работников

## 📱 Адаптивность

Таблица адаптирована для:
- Десктопных экранов
- Планшетов
- Мобильных устройств
- Темной темы оформления

## 🔧 Технические детали

### Файлы:
- `src/components/Analytics/ExcelTable.tsx` - основной компонент
- `src/components/Analytics/ExcelTable.css` - стили
- Интегрирован в `AnalyticsDashboard.tsx`

### Запрос к базе данных:
```sql
SELECT 
  employee_exams.*,
  employees.full_name,
  sections.name as section_name,
  profession_templates.name as profession_name,
  exams.name as exam_name
FROM employee_exams
JOIN employees ON employee_exams.employee_id = employees.id
JOIN sections ON employees.section_id = sections.id  
JOIN profession_templates ON employees.profession_template_id = profession_templates.id
JOIN exams ON employee_exams.exam_id = exams.id
```

## 🚀 Преимущества новой таблицы

1. **Компактность** - каждый работник в одной строке
2. **Наглядность** - все экзамены работника видны сразу
3. **Excel-подобность** - привычная структура данных
4. **Цветовая индикация** - быстрая оценка статусов
5. **Сортировка** - по любой колонке, включая экзамены
6. **Производительность** - оптимизированные запросы

## 📈 Статистика

В нижней части таблицы отображается общее количество записей, что помогает быстро оценить объем данных.
