# Исправление логики создания работников для разных ролей

## Проблема
При создании работника обычными пользователями (не администраторами) экзамены создавались так же, как у администраторов, без системы подтверждения.

## Решение

### 1. Обновлена логика создания экзаменов в useEmployees.ts
- **Для администраторов**: экзамены создаются с пустыми датами для последующего заполнения
- **Для обычных пользователей**: экзамены создаются в статусе `pending` для подтверждения администратором

### 2. Обновлена логика установки дат в ExamManagement.tsx
- **Для администраторов**: даты устанавливаются сразу
- **Для обычных пользователей**: даты отправляются на подтверждение (pending_date)

### 3. Улучшен интерфейс ExamManagement
- Добавлено отображение pending дат
- Разные кнопки и подсказки для разных ролей
- Информационные сообщения о статусе подтверждения

## Логика работы

### Для администраторов (admin, admin_assistant):
1. Создают работника
2. Экзамены создаются с пустыми датами (`exam_date: '1900-01-01'`)
3. Могут сразу устанавливать даты экзаменов
4. Даты сохраняются напрямую в `exam_date` и `next_exam_date`

### Для обычных пользователей (section_chief):
1. Создают работника
2. Экзамены создаются в статусе pending:
   - `exam_date: '1900-01-01'` (пустая)
   - `pending_date: '1900-01-01'` (ожидает установки)
   - `pending_until: NOW() + 7 дней`
3. При установке даты она сохраняется в `pending_date`
4. Администратор должен подтвердить дату через панель подтверждений

## Интерфейс

### Отображение статусов:
- **Обычные экзамены**: зеленый/желтый/красный статус
- **Pending экзамены**: синий статус "Ожидает"
- **Показывается pending дата**: "Ожидает подтверждения: 15.12.2024"

### Кнопки:
- **Для администраторов**: "ОК" (устанавливает сразу)
- **Для обычных пользователей**: "На подтверждение" (отправляет на подтверждение)
