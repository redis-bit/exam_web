# Пошаговое тестирование автоматических уведомлений

## Шаг 1: Запуск приложения
```bash
npm start
```

## Шаг 2: Проверка консоли браузера
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Войдите в систему под любым пользователем
4. Ищите сообщения:
   - ✅ `useNotifications - загружаем данные для пользователя: [UUID]`
   - ✅ `fetchNotifications - загружено уведомлений: [число]`
   - ✅ `Автоуведомления - всего уведомлений: [число]`
   - ✅ `Автоуведомления - непрочитанных: [число]`

## Шаг 3: Создание тестового уведомления (если нет уведомлений)
1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Выполните скрипт из файла `tmp_rovodev_test_notification.sql`
4. Замените `USER_ID_HERE` на реальный UUID пользователя

## Шаг 4: Проверка автопоказа
1. Обновите страницу (F5)
2. Должен появиться модал с уведомлением
3. Проверьте кнопки: "Далее", "Отметить все", "Пропустить все"

## Возможные проблемы:

### Если уведомления не загружаются:
- Проверьте, создана ли таблица `user_notifications`
- Выполните `database/05_notifications_and_approvals.sql`

### Если модал не появляется:
- Проверьте консоль на наличие ошибок
- Убедитесь, что `showAutoModal = true` в отладочных сообщениях

### Если есть ошибки TypeScript:
- Перезапустите сервер разработки
- Проверьте импорты в компонентах
