### 3. Возможные проблемы и решения:

#### Проблема: Неправильные UUID
**Симптом:** Ошибка "invalid input syntax for type uuid"
**Решение:** Проверьте, что `professionTemplateId` и `sectionId` являются валидными UUID

#### Проблема: Отсутствуют права доступа
**Симптом:** Ошибка "permission denied"
**Решение:** Выполните:
```sql
GRANT EXECUTE ON FUNCTION request_employee_creation_hook TO authenticated;
GRANT EXECUTE ON FUNCTION request_employee_creation TO authenticated;
GRANT EXECUTE ON FUNCTION create_user_notification TO authenticated;
```

#### Проблема: Отсутствуют таблицы
**Симптом:** Ошибка "relation does not exist"
**Решение:** Выполните полный скрипт `database/05_notifications_and_approvals.sql`

#### Проблема: Неправильная роль пользователя
**Симптом:** Функция выполняется, но ничего не происходит
**Решение:** Проверьте роль пользователя в таблице `users`
