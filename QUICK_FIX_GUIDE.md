# Быстрое решение проблемы с пользователями

## Проблема
Пользователь создался в `auth.users` (может войти в систему), но не отображается в модуле "Пользователи" у администратора.

## Решение

### Вариант 1: Автоматическая синхронизация (Рекомендуется)

1. **Выполните SQL скрипт** в Supabase Dashboard → SQL Editor:
   ```sql
   -- Скопируйте и выполните содержимое файла:
   database/auto_create_user_profile.sql
   ```

2. **Используйте кнопку синхронизации** в интерфейсе:
   - Войдите как администратор
   - Перейдите в "👤 Пользователи"
   - Нажмите кнопку "🔄 Синхронизировать"
   - Система найдет всех пользователей из `auth.users` и добавит их в таблицу `users`

### Вариант 2: Ручное добавление

1. **Найдите ID пользователя** в Supabase Dashboard → Authentication → Users
2. **Выполните SQL запрос** (замените данные на реальные):
   ```sql
   SELECT add_existing_auth_user_to_users(
     'USER_ID_HERE'::uuid,     -- ID из auth.users
     'Имя Фамилия',            -- Полное имя
     'section_chief',          -- Роль
     'SECTION_ID_HERE'::uuid   -- ID участка (или NULL)
   );
   ```

## Проверка результата

После выполнения любого из вариантов:

1. **Обновите страницу** или нажмите "🔄 Обновить" в модуле пользователей
2. **Проверьте список пользователей** - должен появиться новый пользователь
3. **Протестируйте вход** под этим пользователем

## Предотвращение проблемы в будущем

После выполнения `auto_create_user_profile.sql` все новые пользователи будут автоматически добавляться в таблицу `users` при регистрации через email.

## Полное тестирование системы

### Шаг 1: Создание участка
- Войдите как администратор
- Создайте участок "Тестовый участок"

### Шаг 2: Создание пользователя
- Создайте пользователя через интерфейс ИЛИ
- Зарегистрируйтесь по email и синхронизируйте

### Шаг 3: Создание профессии и работника
- Создайте профессию с экзаменами
- Добавьте работника к профессии

### Шаг 4: Тестирование аналитики
- Перейдите в "📊 Аналитика"
- Проверьте статистику и уведомления

### Шаг 5: Тестирование ролевого доступа
- Выйдите и войдите под пользователем участка
- Убедитесь, что видит только свой участок

## Ожидаемый результат ✅

- Пользователь отображается в списке администратора
- Может войти в систему
- Видит только свой участок (если роль "Начальник участка")
- Аналитика работает корректно
- Цветовая индикация соответствует статусам экзаменов
