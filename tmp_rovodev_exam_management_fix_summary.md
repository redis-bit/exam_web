# Исправление проблемы с обновлением экзаменов работника

## Проблема
При повторном нажатии на кнопку "Экзамены" для работника не отображались назначенные экзамены. Данные не обновлялись при повторном открытии модального окна.

## Решение

### 1. Добавлена кнопка "Обновить"
- Добавлена кнопка для принудительного обновления данных экзаменов
- Функция `refreshExams()` вызывает `loadEmployeeExams()` для перезагрузки данных

### 2. Добавлена кнопка "Добавить экзамен"
- Интегрирован компонент `AddExamModal` в `ExamManagement`
- Добавлена возможность добавлять новые экзамены прямо из окна управления экзаменами

### 3. Улучшен пользовательский интерфейс
- Добавлено состояние загрузки с индикатором
- Добавлено отображение ошибок
- Добавлено сообщение когда у работника нет экзаменов
- Улучшена структура заголовка с группировкой кнопок

### 4. Автоматическое обновление данных
- После добавления нового экзамена данные автоматически обновляются
- После изменения даты экзамена список обновляется
- Вызывается `onUpdate()` для обновления родительского компонента

## Как тестировать

1. Откройте страницу администратора
2. Перейдите во вкладку "Работники"
3. Создайте работника или выберите существующего
4. Нажмите кнопку "Экзамены"
5. Проверьте, что:
   - Отображается кнопка "Обновить"
   - Отображается кнопка "+ Добавить экзамен"
   - При нажатии "Добавить экзамен" открывается модальное окно
   - После добавления экзамена список обновляется
   - При повторном открытии экзаменов данные отображаются корректно
   - Кнопка "Обновить" перезагружает данные

## Результат
Теперь при нажатии на кнопку "Экзамены" пользователь может:
- Видеть все назначенные экзамены работника
- Добавлять новые экзамены
- Обновлять данные вручную
- Изменять даты экзаменов
- Данные корректно обновляются при повторном открытии модального окна
