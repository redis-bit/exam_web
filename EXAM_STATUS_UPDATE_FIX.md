# Исправление проблемы с обновлением статусов экзаменов

## Проблема
После установки даты экзамена статус не всегда обновлялся на "Не подтвержден", что позволяло повторно изменять дату и приводило к ошибкам.

## Исправления в ExamManagement.tsx

### 1. Улучшена логика обновления статуса для пользователей
- Статус "pending" устанавливается немедленно после успешного запроса
- Добавлено поле `pending_date` в локальное состояние
- Убрана немедленная перезагрузка данных, которая перезаписывала локальные изменения

### 2. Добавлена логика для администраторов
- После прямого изменения даты статус сбрасывается на "normal"
- Очищается `pending_date`

### 3. Усилена проверка pending статуса
- Проверка как `status === 'pending'`, так и наличия `pending_date`
- Блокировка повторного редактирования на основе обеих проверок

### 4. Обновлен UI
- Поля ввода и кнопки блокируются при наличии `pending_date`
- Корректные подсказки для заблокированных элементов

## Логика работы

### Для обычных пользователей:
1. Пользователь изменяет дату экзамена
2. Отправляется запрос на подтверждение
3. **Немедленно** устанавливается статус "Не подтвержден" (pending)
4. Поля блокируются до решения администратора
5. Повторное изменение невозможно

### Для администраторов:
1. Администратор изменяет дату напрямую
2. Изменения применяются сразу
3. Статус сбрасывается на "Нормально"
4. `pending_date` очищается

## Проверка исправления

1. **Войдите как обычный пользователь**
2. **Измените дату любого экзамена**
3. **Проверьте, что:**
   - Статус стал "Не подтвержден" (синий)
   - Поле даты заблокировано
   - Кнопка "Сегодня" заблокирована
   - Повторное изменение невозможно

4. **Войдите как администратор**
5. **Подтвердите или отклоните запрос**
6. **Проверьте, что статус обновился корректно**

## Дополнительные улучшения

- Более надежная проверка `pending_date !== null`
- Двойная блокировка UI (по статусу и по `pending_date`)
- Корректное обновление локального состояния без перезагрузки
- Улучшенная обратная связь для пользователя
