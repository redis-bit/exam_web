БЫСТРЫЕ КОМАНДЫ ДЛЯ РАЗВЕРТЫВАНИЯ:

=== ПОДГОТОВКА ===
npm ci
npm run build

=== VERCEL (РЕКОМЕНДУЕТСЯ) ===
npm install -g vercel
vercel login
vercel --prod

=== NETLIFY ===
npm install -g netlify-cli
netlify login
netlify deploy --prod --dir=build

=== DOCKER ===
docker build -t exam-app .
docker run -d -p 8080:8080 --name exam-app exam-app
