# Инструкции по настройке базы данных в Supabase

## Порядок выполнения SQL скриптов

### 1. Откройте SQL Editor в Supabase
- В панели Supabase перейдите в **SQL Editor**
- Нажмите **New query**

### 2. Выполните скрипты в следующем порядке:

#### Скрипт 1: Создание таблиц
```sql
-- Скопируйте содержимое файла database/01_create_tables.sql
-- Вставьте в SQL Editor и нажмите RUN
```

#### Скрипт 2: Функции и триггеры  
```sql
-- Скопируйте содержимое файла database/02_functions_and_triggers.sql
-- Вставьте в SQL Editor и нажмите RUN
```

#### Скрипт 3: Политики безопасности
```sql
-- Скопируйте содержимое файла database/03_rls_policies.sql
-- Вставьте в SQL Editor и нажмите RUN
```

#### Скрипт 4: Тестовые данные
```sql
-- Скопируйте содержимое файла database/04_test_data.sql
-- Вставьте в SQL Editor и нажмите RUN
```

### 3. Проверка результата
После выполнения всех скриптов:

1. Перейдите в **Table Editor**
2. Убедитесь, что созданы все таблицы:
   - sections
   - users  
   - exams
   - profession_templates
   - profession_exams
   - employees
   - employee_exams
   - news
   - backups
   - forum_topics
   - forum_messages

3. Проверьте, что в таблицах есть тестовые данные

### 4. Возможные ошибки и решения

**Ошибка**: "relation already exists"
**Решение**: Таблица уже создана, можно продолжать

**Ошибка**: "function does not exist"  
**Решение**: Убедитесь, что выполнили скрипты в правильном порядке

**Ошибка**: "permission denied"
**Решение**: Убедитесь, что используете правильный проект и имеете права администратора
